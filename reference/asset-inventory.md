# Asset inventory

The first move on any repurposing pass, before generating anything new. Read directly from `GabeYoga-HQ/Detox Book/briefs/LAUNCH-PROMO-IDEAS.md`, content-claude's own dispatch menu.

## The organizing principle

Stated verbatim in the real trail, under the header "THE BIG INSIGHT":

> The book is already a marketing asset library. The 7 signature pages, the Noise Map, the 19 HONESTLY boxes, the 9 quote-spreads, the ancient echoes — all finished, on-brand, screenshot-ready. ~40 launch visuals already exist inside the PDF. Don't re-create them; export them. The launch can literally be "the book's own pages, released one a day."

The move this licenses: **catalogue before you create.** A manuscript that's gone through a real revision/rhythm pass already contains finished, on-voice material shaped for exactly this purpose — it doesn't need a marketing team to reinvent it, it needs someone to find it and export it in the format a channel actually wants.

## What counts as an inventory candidate

From the real trail, five concrete asset classes, each with a real example:

1. **Signature pages / signature lines** — a manuscript's most-quoted, most memorable sentences, already written to stand alone. Real examples: *"You cannot hear a whisper in a stadium."* · *"You stopped being able to hear yourself."*
2. **A core diagram** — a book's central visual/conceptual model, if it has one. Real example: the Noise Map (seven named noises → loss of signal → pause → listening) — described in the real trail as "the most 'that's me' diagram in the book," and independently flagged in the animation brief as "the single highest-impact asset... the diagram was *built* to animate."
3. **Debunk / myth-correction boxes** — a manuscript's own honesty-argument moments, where it corrects a common claim rather than making one. Real example: "MYTH: Detox flushes toxins out of your body. HONESTLY: your liver and kidneys already do that."
4. **Quote-spreads** — passages already formatted or clearly suited to stand alone as a pull-quote, independent of chapter context.
5. **Cross-tradition or historical grounding moments** ("ancient echoes") — where the manuscript connects its claim to a long-standing, independently-arrived-at tradition, without claiming that tradition as scientific proof. Real example: a Patanjali line paired with the explicit framing "not ancient mysticism against modern science... both are describing the same quiet."

## How to run the inventory

1. **Read the manuscript (or the relevant chapter/stage output) for candidates in each class above.** Don't limit the search to material the author or operator has already flagged — the real trail's own value was in surfacing material nobody had named as marketing-ready yet.
2. **Note the source location** for each candidate (chapter, page, or file), so a caption or card can cite it precisely later.
3. **Don't generate replacement copy for a class with no real candidate.** If a manuscript has no clear central diagram, say so — an empty inventory slot is honest; inventing a diagram to fill it is not (see `rules.md`'s empty-input handling).
4. **Flag "musical" candidates from a completed rhythm pass first**, if `book-ghostwriting-skill` Stage 5 output is available — refrains the author's own revision pass already marked as landing well are the strongest repurposing candidates, stronger than a line pulled cold from a first draft.
5. **Hand the finished inventory to classification** (`rules.md`'s routing table) — each candidate still needs to be checked: is it native to the book, or does it borrow/adapt material from somewhere else and apply it here? See `reference/seam-legibility.md` for that second case.

## Worked reference — the real inventory's scale

One manuscript (*Are You Actually Hungry?*) produced, on a single inventory pass: 7 signature pages, 1 core diagram (the Noise Map), 19 debunk/honesty boxes, 9 quote-spreads, and an unspecified number of cross-tradition "ancient echo" moments — roughly 40 launch visuals total, from a book that was never written with a content calendar in mind. This is the real scale an inventory pass can expect to find in a manuscript that's gone through a genuine revision process; a thinner or less-revised manuscript may inventory smaller, and that's a real finding, not a failure of the pass.
