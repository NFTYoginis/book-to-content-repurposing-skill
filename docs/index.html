The honesty gate — run on every derived claim

Repurposing compresses a manuscript's careful qualifiers into a 12-second caption. The same discipline has to survive that compression.

ConstraintWhat's checked
Lifespan / "live longer" claimsAbsent entirely, not softened
"Removes / flushes / eliminates" languageOnly if the manuscript itself supports it — otherwise it's the myth, not the claim
Physiological promisesAwareness claim ≠ physiological claim — kept distinct
Authority framePersonal practice, direct observation — never supervision
Standing disclaimerOn-screen footer + in the caption text, every time

Setup

  1. Load this folder into a Claude Project, or point a Claude Code session at it — SKILL.md lets it auto-discover and trigger from a natural request.
  2. Bring the finished or near-finished manuscript — ideally with a completed rhythm-pass flagging its strongest refrains.
  3. Let it run the inventory pass first — no new content is generated before the export-ready material is catalogued.
  4. Classify each candidate as native or applied/borrowed; applied material gets the full seam-legibility frame, no exceptions.
  5. Run the honesty-gate checklist on every asset before it ships to design.

FAQ

Does it design the actual cards or reels?

No. It produces captions, scripts, and on-screen-text specs — final visual rendering is the design worker's job.

What if the manuscript doesn't have much to inventory?

It says so. An empty or thin inventory slot is a real finding — it doesn't invent a diagram or a signature line to fill a content calendar.

Can I skip the "applied" chip if the line is obviously a metaphor?

No — see the refusal gate. The better a borrowed line fits, the higher the misattribution risk, not the lower.

Does it build the launch funnel around this content?

No — that's Book Launch & Funnel Strategy. This one supplies the content; it doesn't architect the cascade.
