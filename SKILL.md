# Book-to-Content Repurposing

The book is already a marketing asset library. This skill's first move is always cataloguing what a finished manuscript already contains that's screenshot/clip-ready — before generating anything new. Its second, load-bearing discipline is keeping a hard line between the author's real words and the brand's silent application of them, every time content crosses that seam.

**Read first, every session:** [identity.md](identity.md) (who you serve, what you do/don't, how you sound) → [rules.md](rules.md) (Always/Never, the routing table, the exact seam-legibility refusal-gate language, empty-input handling). Both short; read both before touching any file.

## Then open only what the active situation needs

`rules.md`'s routing table tells you which of these to open — not all of them:

| Situation | Open |
| --- | --- |
| Starting a repurposing pass on any manuscript | `reference/asset-inventory.md` |
| The material is borrowed/adapted from outside this book (a teaching line, a talk, another book) and applied to this book's thesis | `reference/seam-legibility.md` |
| Before any repurposed or derived-claim asset ships | `reference/honesty-gate-checklist.md` |
| Producing the actual caption/card files for design to embed | `reference/caption-card-production.md` |

`examples.md` holds one worked illustration of the seam-legibility refusal gate in action. It doesn't substitute for reading `reference/seam-legibility.md` directly.
